# Account Management System Test Plan

## Scope and execution notes

This plan characterizes the current COBOL application in `src/cobol/`. It covers the menu, balance display, credit and debit rules, in-memory balance handling, and exit behavior. The program handles one generic account; it has no customer records, file/database persistence, fees, or maximum-balance validation.

Run the compiled application from a fresh process for each case unless the pre-condition says to continue an existing session. The starting balance is `1000.00`. For cases that inspect multiple operations, carry the balance forward in the same process. Record the observed output and outcome in the **Actual Result**, **Status (Pass/Fail)**, and **Comments** columns. A status of `Not Run` is a placeholder, not a pass.

The amount field is an unsigned numeric value with up to six integer digits and two decimal places. Balance output is zero-padded to six integer digits (for example, `001000.00`). Invalid textual or out-of-range numeric input is not given a defined business response by the current code; such behavior should be recorded rather than assumed.
